二、总体结论

当前评级：

策略思想：A级 工程实现：B-级 直接实盘风险：较高

策略框架已经具备专业量化系统雏形，包括： - BO突破 - TR趋势 - RB反转 -
多周期过滤 - ATR风险控制 - 动态止盈 - Trailing - 时间退出

但代码实现仍存在： 1. 状态机不完整； 2. 风控变量定义不统一； 3.
部分功能只有接口，没有实际执行； 4. 回测可能高估收益； 5.
实盘行为可能与回测结果不一致。

三、P0级问题（必须修复）

P0-1：盈亏单位体系混乱

当前存在三种单位： - 价格百分比 - 杠杆后收益百分比 - 保证金百分比

例如： 实际价格亏损2%，10倍杠杆后可能被代码认为亏损20%。

影响： - 提前止损； - 收益曲线失真； - 风险模型错误。

建议： 统一变量：

price_move_pct position_pnl_pct margin_loss_pct

三个概念禁止混用。

P0-2：离场系统不是完整状态机

当前结构：

check_exit() | return

缺少：

PositionState | + stop_loss更新 + trail更新 + ladder更新 + 部分仓位更新

导致： - 保本止损可能无效； - Trailing状态可能丢失； -
阶梯止盈可能重复触发； - REBOUND缩损可能没有执行。

P0-3：回测成交模型风险

如果使用同一根K线的high/low判断成交，会产生K线内部顺序未知问题。

15分钟K线：

可能： 开 -> 低 -> 高 -> 收

也可能： 开 -> 高 -> 低 -> 收

结果不同。

建议： 使用5分钟数据模拟15分钟策略执行。

需要在文档明确：

15m策略逻辑不改变，5m数据仅用于提高成交模拟精度；实盘使用实时数据。
